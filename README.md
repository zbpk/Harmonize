# Harmonize 🎵

Harmonize is a Python desktop music player. Play local songs, download tracks online, view live scrolling lyrics, manage playlists, track listening stats, and connect with friends!

---

### ✨ Features

- **Music Player:** Play local songs and organize custom playlists.
- **Downloads:** Search for music online and download tracks directly.
- **Live Lyrics:** View synchronized, scrolling lyrics as tracks play.
- **Stats & Badges:** Track your total listening time and earn achievements.
- **Social:** Follow friends, view profiles, and see what others are listening to.
